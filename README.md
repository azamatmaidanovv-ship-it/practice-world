# Practice World

Сайт для подготовки к ҰБТ (ЕНТ) на казахском языке: регистрация, выбор школьного предмета,
тесты с таймером, разбор ответов, профиль и рейтинг.

## Запуск

Просто откройте `index.html` двойным щелчком — сайт работает без сервера и интернета.

Либо запустите локальный сервер (удобно для телефона в той же сети):

```powershell
python -m http.server 8811
```

и откройте `http://localhost:8811`.

## Что внутри

| Файл | Назначение |
| --- | --- |
| `index.html` | точка входа |
| `style.css` | оформление (тёмная тема, адаптив) |
| `questions.js` | банк вопросов: 12 предметов, 600 вопросов |
| `app.js` | регистрация, тесты, результаты, профиль, рейтинг |

## Возможности

- Регистрация и вход (данные хранятся локально в `localStorage` браузера).
- Переключение тёмной и светлой темы кнопкой ☀ / 🌙 в шапке; выбор сохраняется.
- 12 предметов: математика, физика, химия, биология, информатика, қазақ тілі,
  қазақ әдебиеті, Қазақстан тарихы, дүниежүзі тарихы, география, ағылшын тілі, орыс тілі.
- Каждый тест: 50 вопросов (весь банк предмета), 50 минут, 5 вариантов ответа (как в ҰБТ).
- Поддержка вопросов с несколькими правильными ответами (2–3): такие вопросы
  помечены значком «Бірнеше жауап», балл начисляется за полное совпадение набора.
- Таймер, навигация по вопросам, горячие клавиши `1–5` и `←` / `→`.
- Результат с процентом, разбором каждого вопроса и сохранением в историю.
- Профиль со статистикой и таблица лидеров между аккаунтами на этом устройстве.

## Как добавить вопросы

Откройте `questions.js` и добавьте объект в массив `questions` нужного предмета:

```js
{ q: "Текст вопроса?", o: ["дұрыс жауап", "нұсқа 2", "нұсқа 3", "нұсқа 4", "нұсқа 5"] }
```

Первый элемент массива `o` — правильный ответ по умолчанию. При запуске теста варианты
перемешиваются автоматически.

Если у вопроса несколько правильных ответов (2–3), укажите их индексы в поле `a`
(правильные варианты удобно ставить первыми):

```js
{ q: "Қайсылары жұп сандар?", o: ["12", "7", "24", "33", "8"], a: [0, 2, 4] }
```

Такой вопрос автоматически станет мультивыбором: ученик сможет отметить несколько
вариантов, а балл начислится только за полный правильный набор.
